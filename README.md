# INSPIRA — Interior Design Blogging Website

A frontend academic project built using **HTML, CSS and JavaScript**.

## Features
- Responsive interior design frontend
- Explore interior designs
- Search and filter by room/style
- Save favourite designs using JavaScript localStorage
- Material inspiration guide
- Interior design blog
- Registration and login form validation
- No database/backend required
- GitHub Pages compatible

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best experience, use VS Code with the Live Server extension.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all project files and folders.
3. Go to Settings → Pages.
4. Select the `main` branch and `/root` folder.
5. Save and open the generated GitHub Pages link.

## Important
The images use remote Unsplash URLs, so internet access is required for those images. The login/account demonstration uses browser localStorage because this project does not use a database.
